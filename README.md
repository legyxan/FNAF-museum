# Виртуальный музей аниматроников Freddy's

Консольное приложение на C++ в стиле ООП. Моделирует виртуальный музей,
посвящённый аниматроникам из вселенной Five Nights at Freddy's.

**Дисциплина:** ООП в C++, V семестр
**Проектная работа № 2**

## Возможности программы

| № | Пункт меню | Описание |
|---|---|---|
| 1 | Показать все экспонаты | Полный список с авторами, залами и отзывами |
| 2 | Показать список залов | Залы с числом экспонатов и средним рейтингом |
| 3 | Зайти в зал | Просмотр экспонатов конкретного зала (по номеру) |
| 4 | Найти экспонат | Поиск по имени или автору |
| 5 | Оставить отзыв | Добавление отзыва (оценка 1–5 + текст) |
| 6 | **[ФИШКА]** Топ-3 экспоната | Сортировка по среднему рейтингу отзывов |
| 7 | **[ФИШКА]** Рейтинг залов | Сортировка залов по среднему баллу |
| 8 | Сохранить данные в файл | Запись изменений обратно в `exhibits.csv` и `reviews.txt` |
| 9 | Показать отзывы об экспонате | Полный список отзывов с автором и оценкой |
| 0 | Выход | Завершение работы |
